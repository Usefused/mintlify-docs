Harnest discovers extensions in `extensions/<name>/extension.yaml` (plus any pack-owned extensions embedded in a branded CLI binary).

## Install an extension

From your agent folder, install from PyPI or from a local directory, then sync dependencies:

```bash
# From PyPI (short slug or full harnest-extension-* name)
harnest extensions install warehouse
harnest env sync .

# From a local source directory
harnest extensions install ../harnest-extension-warehouse
harnest env sync .
```

- Pass `--force` to replace an existing extension cleanly.
- To find compatible public `harnest-extension-*` packages on PyPI:

```bash
harnest extensions search warehouse
```

`official` marks Fused-maintained packages; `community` means the wheel passes structural manifest and entry-point checks (not a security audit).

<Warning>
`pip install` alone does not register an extension with an agent. Always install via `harnest extensions install` (which validates and copies into `extensions/<name>/`) and run `harnest env sync .`.
</Warning>

## Use the extension in your agent

### Contributed tools, skills, MCP, and lifecycle hooks

If the extension declares `tools`, `mcp`, `skills`, `subagents`, or `lifecycle` under `contributes:` in `extension.yaml`, Harnest wires them automatically at compile time—no imports required.

### Calling the extension's Python API

After compilation, Harnest exposes the extension under `harnest.extensions.<name>`. Call methods on its `extension` singleton inside any Agent Tool:

```python tools/query_warehouse.py
from harnest.agent import tool
from harnest.extensions.warehouse import extension as warehouse

@tool
async def query_warehouse(statement: str) -> list[dict]:
    """Query the warehouse through its Harnest Extension."""
    return await warehouse.query(statement)
```

Inside helper modules, you can also resolve the current request's typed [`ExtensionContext`](/harnest/reference/api/extensions#extensioncontext) explicitly:

```python lib/warehouse_service.py
from harnest import context
from harnest.extensions.warehouse import WarehouseContext

async def run_query(statement: str) -> list[dict]:
    warehouse = context.extensions("warehouse", WarehouseContext)
    return await warehouse.query(statement)
```

[`Extension.context`](/harnest/reference/api/extensions#extension-context) is scoped to the active request—holding onto it after the request finishes raises [`ExtensionContextUnavailableError`](/harnest/reference/api/extensions#extensioncontextunavailableerror).
