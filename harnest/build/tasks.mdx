Tasks run application work outside the requesting model tool call. Declare public tasks in `tasks/` and recurring work in `cron/`; Cron creates its queued task automatically.

| Need | Use |
|---|---|
| Retryable work that a tool or trusted service starts | `await task.defer(...)` |
| Wait for queued work from an agent invocation | Async `@tool(durable=True)` |
| Start work at a fixed UTC schedule | `@cron("...")` under [`cron/`](/harnest/build/scheduled-tasks) |
| Let managed code create or control a user's recurring schedule | [Dynamic schedules](/harnest/build/dynamic-schedules) |
| Ordinary in-process reuse | Call the decorated task directly |
