Every `@pack.initialize` and `@pack.migration` hook receives [`context: ProjectContext`](/harnest/reference/api/authoring#projectcontext) and returns a [`ChangePlan`](/harnest/reference/api/authoring#changeplan). Hooks never write directly to disk—Harnest validates and applies the plan atomically.

## `ProjectContext` and `ChangePlan` reference

| Member | Type / returns | Purpose |
|---|---|---|
| [`context.name`](/harnest/reference/api/authoring#projectcontext) | `str` | Target agent directory name (for example `"sales"`). |
| [`context.options`](/harnest/reference/api/authoring#projectcontext) | `BaseModel \| None` | Validated CLI `--option` values, or `None`. |
| [`context.files.read_text(path)`](/harnest/reference/api/authoring#projectcontext-files-read_text) | `str` | Read a staged UTF-8 file. |
| [`context.files.write_text(path, content, *, policy=...)`](/harnest/reference/api/authoring#projectcontext-files-write_text) | Operation | Create or update a text file. |
| [`context.files.from_template(path, *, template, values=None, policy=...)`](/harnest/reference/api/authoring#projectcontext-files-from_template) | Operation | Copy a UTF-8 file from `templates/` with optional `$var` substitution. |
| [`context.files.from_file(path, *, source, policy=...)`](/harnest/reference/api/authoring#projectcontext-files-from_file) | Operation | Copy text or binary bytes verbatim from `templates/` (no `$` substitution). |
| [`context.files.from_folder(path, *, source=None, policy=...)`](/harnest/reference/api/authoring#projectcontext-files-from_folder) | `ChangePlan` | Recursively copy every file in a folder under `templates/` (defaults `source` to `path`). |
| [`context.files.delete(path)`](/harnest/reference/api/authoring#projectcontext-files-delete) | Operation | Delete an unchanged pack-owned file. |
| [`context.yaml.read(path)`](/harnest/reference/api/authoring#projectcontext-yaml-read) | `dict[str, Any]` | Read a staged YAML mapping (`{}` if absent). |
| [`context.yaml.set(path, *, key, value, policy=...)`](/harnest/reference/api/authoring#projectcontext-yaml-set) | Operation | Set one nested YAML key tuple while keeping unrelated keys. |
| [`context.yaml.rename_key(path, *, source, destination)`](/harnest/reference/api/authoring#projectcontext-yaml-rename_key) | Operation | Rename a YAML key while keeping the team's current value. |
| [`ChangePlan(*operations)`](/harnest/reference/api/authoring#changeplan) | `ChangePlan` | Ordered operations to apply (`ChangePlan()` for no-op). |
| [`WritePolicy`](/harnest/reference/api/authoring#writepolicy) | Enum | `WritePolicy.IF_MISSING` (default) or `WritePolicy.MANAGED`. |

Set `templates="templates"` on [`ProjectPack`](/harnest/reference/api/authoring#projectpack) when using `from_template` or `from_file`.

## Write text, templates, and verbatim files

```text templates/team-notes.txt
Agent: $agent
Team: $team
```

```python pack.py
from harnest.authoring import ChangePlan, ProjectContext, ProjectPack, WritePolicy

pack = ProjectPack(schema_version=1, templates="templates")

@pack.initialize
def initialize(context: ProjectContext) -> ChangePlan:
    return ChangePlan(
        # Inline text
        context.files.write_text("company-notes.md", "Contact #platform.\n"),
        # Render `$var` placeholders (use `$$` for a literal `$`; omit `values` for raw copy)
        context.files.from_template(
            "team-notes.txt",
            template="team-notes.txt",
            values={"agent": context.name, "team": context.options.team},
        ),
        # Copy verbatim (Markdown, JSON, PDFs, images — never substitutes `$`)
        context.files.from_file("docs/handbook.pdf", source="handbook.pdf"),
        # Copy an editable starter lifecycle hook
        context.files.from_file("lifecycle/output.py", source="lifecycle/output.py"),
        # Recursively copy a whole folder from templates/ (source defaults to path)
        context.files.from_folder("lib", policy=WritePolicy.MANAGED),
    )
```

## Read, set, and rename YAML keys

Keys are **tuples** of strings so dotted keys stay unambiguous:

```python pack.py
@pack.initialize
def initialize(context: ProjectContext) -> ChangePlan:
    return ChangePlan(
        # Writes `deployment: { region: "eu-west" }`
        context.yaml.set("acme-agent.yaml", key=("deployment", "region"), value="eu-west"),
        # Writes literal key `"deployment.region": "eu-west"`
        context.yaml.set("acme-agent.yaml", key=("deployment.region",), value="eu-west"),
    )

@pack.migration(from_version=1, to_version=2)
def migrate(context: ProjectContext) -> ChangePlan:
    current = context.yaml.read("acme-agent.yaml")
    if "owner" not in current:
        return ChangePlan()
    return ChangePlan(
        context.yaml.rename_key("acme-agent.yaml", source=("owner",), destination=("team",)),
    )
```

## Write policies

| Policy | Target absent | Target already exists |
|---|---|---|
| `WritePolicy.IF_MISSING` *(default)* | Create and record ownership. | Leave untouched. |
| `WritePolicy.MANAGED` | Create and record ownership. | Replace only if unchanged since the pack wrote it; otherwise block for review. |

```python pack.py
@pack.migration(from_version=1, to_version=2)
def update_workflow(context: ProjectContext) -> ChangePlan:
    return ChangePlan(
        context.files.from_template(
            ".github/workflows/agent.yml",
            template="ci.yml",
            policy=WritePolicy.MANAGED,
        ),
    )
```

## Constraints

- **Paths:** Canonical agent-relative POSIX paths only—no `/`, `..`, symlinks, `.git/`, `.harnest/`, `.venv/`, or `harnest-packs.lock`.
- **YAML:** Single-document mappings with unique keys; comments and formatting are normalized on write.
- **Snapshots & conflicts:** Reads reflect the state before the current hook ran. Overlapping ownership between two packs blocks the plan; see [resolve blockers](/harnest/build/project-packs/plans-and-recovery#resolve-blockers).
