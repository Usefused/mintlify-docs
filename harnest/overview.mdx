## Focus on what your agent does

Whether you’re building a support assistant, an internal knowledge tool, or an operations workflow, Harnest gives you a place for each part of the application.

| What you need | What Harnest provides |
|---|---|
| Connect to your business | [Agent Tools](/harnest/build/agent-tools) and [MCP Client](/harnest/build/mcp-client) connections for your APIs and services |
| Reuse expertise | [Agent Skills](/harnest/build/agent-skills), [SubAgents](/harnest/build/subagents), and [Agent Plugins](/harnest/build/agent-plugins) |
| Share application capabilities across agents | [Harnest Extensions](/harnest/build/extensions) package reusable functionality and lifecycle integrations |
| Check behavior before shipping | Tests, evaluations, and a local playground |
| Run beyond a single request | Session storage, checkpoints, approvals, and durable task capabilities |
| Fit your production environment | Authentication hooks, telemetry, compiled artifacts, and a serving API |

Start with the capabilities you need. Configure persistent services, authentication, and deployment as you move toward production. The [production guide](/harnest/runtime/serving/production) covers that next step.

## Start with code or Studio

Install Harnest on macOS or Linux. No preinstalled Python is required.

```bash
curl -fsSL \
  https://raw.githubusercontent.com/Usefused/harnest/main/install.sh |
  sh
```

See [installation options](/harnest/get-started/install), or create your first project:

```bash
harnest init support-agent --framework adk
cd support-agent
```

Use `--framework langgraph` if you prefer LangGraph. [Configure your model](/harnest/build/models-and-libraries/configure-a-model), edit `instructions.md`, then test and serve:

```bash
harnest test .
harnest serve . --reload
```

Open the playground at `http://127.0.0.1:1907/` to try it. Prefer a visual workspace? Launch [Harnest Studio](/harnest/build/testing-and-compilation#review-changes-in-agent-builder) with `harnest studio --workspace /path/to/agents`.

Already have an agent? [Bring it into Harnest](/harnest/get-started/migrate) in advanced mode to keep direct framework control, then adopt managed capabilities at your own pace.
