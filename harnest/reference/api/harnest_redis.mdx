## RedisStore

Combined storage with atomic task leases and cron occurrence handoff.

Tasks have no expiration: durable retention follows explicit lifecycle
operations, independent of the session/checkpoint TTL configuration.
Configure Redis persistence and replication for the required durability.

```python
RedisStore(
    url: str,
    *,
    prefix: str = 'harnest',
    session_ttl_seconds: int | None = None,
    checkpoint_ttl_seconds: int = 604800,
    lease_seconds: int = 60,
    lease_wait_seconds: float = 30,
    client_options: Mapping[str, Any] | None = None,
) -> None
```

Fields (`—` means no declared default):

| Field | Type | Default |
|---|---|---|
| `owner` | `CheckpointOwner` | `'harnest'` |
| `framework` | `str \| None` | `None` |
| `schema_id` | `str` | `'harnest-checkpoint/v1'` |

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `url` | `str` | Required | Redis connection URL. |
| `prefix` | `str` | `'harnest'` | Prefix for every Redis key the store writes. |
| `session_ttl_seconds` | `int \| None` | `None` | Expire sessions after this many seconds. `None` keeps them. |
| `checkpoint_ttl_seconds` | `int` | `604800` | Expire checkpoint runs after this many seconds. |
| `lease_seconds` | `int` | `60` | How long the lease stays valid, in seconds. |
| `lease_wait_seconds` | `float` | `30` | How long to wait for a session lease before giving up, in seconds. |
| `client_options` | `Mapping[str, Any] \| None` | `None` | Extra options for the Redis client. |

```python
from harnest_redis import RedisStore

store = RedisStore(url=...)
```
