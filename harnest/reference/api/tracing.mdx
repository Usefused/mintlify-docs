## traced

Trace a synchronous or asynchronous authored function.

```python
traced(
    name: str | None = None,
    *,
    attributes: Mapping[str, Any] | None = None,
    kind: Any | None = None,
    **attribute_values: Any,
) -> Callable[[_T], _T]
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `name` | `str \| None` | `None` | Span name. Defaults to the function's qualified name. |
| `attributes` | `Mapping[str, Any] \| None` | `None` | Span attributes. |
| `kind` | `Any \| None` | `None` | OpenTelemetry span kind. |
| `**attribute_values` | `Any` | Optional | More attributes as keyword arguments. |

```python

    ...
```
