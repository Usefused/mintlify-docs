### FusedMCPClient.from_openapi

```python
FusedMCPClient.from_openapi(
    *specs: OpenAPISpec | str | Path,
    name: str,
    url_env: str | None = None,
    token_env: str | None = None,
    webhook_attachment: str | None = None,
    **client_options: Any,
) -> FusedMCPClient
```

Declare one MCP connection spanning all specs without provisioning it.

Strings are shorthand for `OpenAPISpec` with all operations selected.
`client_options` are the standard `MCPClient.streamable_http` options.
Authorization always uses an execution-token environment reference.
`webhook_attachment` names a `kind: webhook` registration (see
`FusedAdminClient.apply_webhook_config`) whose inbound events this
server's resources should also surface, letting any connected service
become a channel's event source alongside its outbound tool calls.

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `*specs` | `OpenAPISpec \| str \| Path` | Optional | One or more `OpenAPISpec` values. A plain path or URL selects every operation of that spec. |
| `name` | `str` | Required | Name of the Fused MCP server, such as `"business"`. |
| `url_env` | `str \| None` | `None` | Environment variable that holds the server URL. Defaults to a name derived from `name`. |
| `token_env` | `str \| None` | `None` | Environment variable that holds the Fused MCP execution token. Defaults to a name derived from `name`. |
| `webhook_attachment` | `str \| None` | `None` | Name of a Fused webhook registration whose inbound events this server's resources also surface. |
| `**client_options` | `Any` | Optional | Standard `MCPClient.streamable_http` options, such as `prefix` or `permission`. |

## OpenAPISpec

One source service; omitted operations select its entire operation surface.

`version` supplies the provider version only when the spec omits it.
`auth` identifies credentials already managed in the chosen Fused bucket.
Source paths resolve against the project passed to `setup`.

```python
OpenAPISpec(
    source: str | Path,
    name: str | None = None,
    operations: Sequence[str] | None = None,
    version: str | None = None,
    auth: Mapping[str, str] | None = None,
    scopes: Sequence[str] | None = None,
) -> None
```

Fields (`—` means no declared default):

| Field | Type | Default |
|---|---|---|
| `source` | `str \| Path` | `—` |
| `name` | `str \| None` | `None` |
| `operations` | `Sequence[str] \| None` | `None` |
| `version` | `str \| None` | `None` |
| `auth` | `Mapping[str, str] \| None` | `None` |
| `scopes` | `Sequence[str] \| None` | `None` |

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `source` | `str \| Path` | Required | Local OpenAPI path, relative to the setup project, or an HTTP(S) URL. |
| `name` | `str \| None` | `None` | Unique lowercase service slug. Defaults to the file name stem. |
| `operations` | `Sequence[str] \| None` | `None` | Exact operation IDs to include. `None` includes every operation. |
| `version` | `str \| None` | `None` | Provider version to use when the spec does not declare one. |
| `auth` | `Mapping[str, str] \| None` | `None` | Fused credential selector with `type`, `name`, and optional `ref`. Credentials stay in Fused. |
| `scopes` | `Sequence[str] \| None` | `None` | Provider connection scopes. |

```python
from harnest_fused import OpenAPISpec

spec = OpenAPISpec(source=...)
```

</Accordion>

## slack_mention

Normalize a verified Fused Slack envelope, rejecting foreign installations and bots.

Call only from the authenticated generated SDK receiver. IDs in a raw public
HTTP request are not proof of provider signature or connection ownership.

```python
slack_mention(payload: Mapping[str, Any], *, installation_id: str, app_id: str) -> ChannelEvent | None
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `payload` | `Mapping[str, Any]` | Required | Verified Fused Slack event envelope. |
| `installation_id` | `str` | Required | ID of one installed channel connection, such as one Slack workspace. |
| `app_id` | `str` | Required | Fused app ID. Events for other apps are rejected. |

```python
from harnest_fused import slack_mention

event = slack_mention(payload=..., installation_id=..., app_id=...)
```
