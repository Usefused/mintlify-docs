## ExtensionStartContext

Application facts available while one same-process extension starts.

The context deliberately excludes invocation credentials and framework
storage authorities. Extensions may reuse only explicitly named application
storage whose lifecycle Harnest has already started.

Obtain this object from the owning Harnest API; its constructor includes runtime bindings.

Fields (`—` means no declared default):

| Field | Type | Default |
|---|---|---|
| `extension_name` | `str` | `—` |
| `framework` | `str` | `—` |
| `root_agent_name` | `str` | `—` |

<Accordion title="Example">

```python
from harnest.extensions import ExtensionStartContext

context: ExtensionStartContext  # obtained from a Harnest API, not constructed directly
```

</Accordion>
