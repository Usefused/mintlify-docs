## Workflow operations

| Operation | Result | Ownership |
|---|---|---|
| `run(name, input)` | `HatchetRun` | Submit and return immediately; the caller owns any later wait |
| `status(job)` | `HatchetRunStatus` | Read `QUEUED`, `RUNNING`, `COMPLETED`, `CANCELLED`, or `FAILED` |
| `wait(job)` | JSON mapping | Persist a continuation and resume when an existing run terminates |
| `run_and_wait(name, input)` | JSON mapping | Prove durable suspension support before submitting and waiting |
| `cancel(job)` | None | Request provider cancellation without claiming worker termination |

## HatchetContext

Typed invocation view exposed through `context.extensions("hatchet")`.

```python
HatchetContext(extension_name: str, owner: 'HatchetExtension') -> None
```

### HatchetContext.extension_name

Return the extension whose invocation authority this context carries.

### HatchetContext.active

Report whether the owning managed invocation is still active.

### HatchetContext.continuations

Return provider-bound suspension authority for this invocation.

### HatchetContext.run

```python
async HatchetContext.run(workflow_name: str, job_input: Mapping[str, Any]) -> HatchetRun
```

Submit external work without waiting in the agent request.

### HatchetContext.status

```python
async HatchetContext.status(job: HatchetRun) -> HatchetRunStatus
```

Read one external job status through invocation credentials.

### HatchetContext.wait

```python
async HatchetContext.wait(job: HatchetRun) -> Mapping[str, Any]
```

Suspend this tool continuation until Hatchet reaches a terminal state.

### HatchetContext.run_and_wait

```python
async HatchetContext.run_and_wait(workflow_name: str, job_input: Mapping[str, Any]) -> Mapping[str, Any]
```

Preflight durable suspension before submitting external work.

### HatchetContext.cancel

```python
async HatchetContext.cancel(job: HatchetRun) -> None
```

Request cancellation while leaving worker shutdown to its owner.
