## Project selection and authored helpers

`bundle_agent(anchor, root)` bundles an authored agent using the project framework selected by Harnest. It requires compilation or an active invocation.

## compile_agent

Compile a filesystem definition into its framework-specific target.

`source` may be the agent directory or its `agent.py` file. Authored
modules import the compiler-provided namespace explicitly, for example
`from harnest.agent import Agent`. The Harnest compiler/runtime provides
that namespace; it does not belong in the agent's requirements file.

```python
compile_agent(
    source: str | Path,
    *,
    entrypoint: str = 'agent:root_agent',
    framework: str = 'adk',
    mode: str = 'managed',
) -> Any
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `source` | `str \| Path` | Required | Agent folder to compile. |
| `entrypoint` | `str` | `'agent:root_agent'` | Module and attribute of the root, such as `"agent:root_agent"`. |
| `framework` | `str` | `'adk'` | Agent framework, `"adk"` or `"langgraph"`. |
| `mode` | `str` | `'managed'` | `"managed"` or `"advanced"`. |

```python
from harnest.bundle import compile_agent

result = compile_agent(source=...)
```

</Accordion>

## bundle_agent

Discover sibling resources and lower with Harnest's selected framework.

Pass `__file__` from an agent folder's `agent.py`. Public Python files
below `tools/`, `subagents/`, and `mcp/` are imported in
sorted path order and must export an object named after their file stem.
Directory-first `plugins/` contribute MCP clients and skills without an
aggregation import.

```python
bundle_agent(anchor: str | Path, root: AgentDefinition) -> Any
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `anchor` | `str \| Path` | Required | Pass `__file__` from the agent module. Sibling resources are discovered next to it. |
| `root` | `AgentDefinition` | Required | The root agent definition. |

```python
from harnest.bundle import bundle_agent

result = bundle_agent(anchor=..., root=...)
```

</Accordion>
