## LiteLLMModel

A provider-neutral model routed through a framework LiteLLM adapter.

`model` must use LiteLLM's explicit `provider/model` form. All keyword
arguments reach the underlying LiteLLM completion call, including provider
settings such as `api_base`, `api_key`, and generation options.
`thinking` selects a portable on/off mode; omit it to use the provider
default or pass `reasoning_effort` directly for provider-specific levels.
`prompt_cache` enables provider prompt-cache breakpoints where the
provider requires them; it defaults to `True` and never changes OpenAI or
Gemini requests.

```python
LiteLLMModel(
    model: str,
    *,
    thinking: bool | None = None,
    lifecycle: LiteLLMLifecycle | None = None,
    prompt_cache: bool = True,
    **completion_args: Any,
) -> None
```

Fields (`—` means no declared default):

| Field | Type | Default |
|---|---|---|
| `model` | `str` | `—` |
| `completion_args` | `Mapping[str, Any]` | `—` |
| `lifecycle` | `LiteLLMLifecycle \| None` | `None` |
| `prompt_cache` | `bool` | `True` |

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `model` | `str` | Required | LiteLLM model ID in `provider/model` form. |
| `thinking` | `bool \| None` | `None` | Turn reasoning on or off. Omit for the provider default. |
| `lifecycle` | `LiteLLMLifecycle \| None` | `None` | Optional `LiteLLMLifecycle` that owns the transport. |
| `prompt_cache` | `bool` | `True` | Add provider prompt-cache breakpoints where needed. |
| `**completion_args` | `Any` | Optional | Extra LiteLLM arguments, such as `api_base`, `api_key`, or `temperature`. |

```python

model = LiteLLMModel("openai/your-model", api_base="https://models.example.invalid/v1")
```

### LiteLLMModel.from_openai_environment

```python
LiteLLMModel.from_openai_environment(
    *,
    default_model: str | None = None,
    thinking: bool | None = None,
    lifecycle: LiteLLMLifecycle | None = None,
    prompt_cache: bool = True,
    **completion_args: Any,
) -> 'LiteLLMModel'
```

Use an explicitly configured OpenAI-compatible API, not a default vendor.

OPENAI_MODEL and OPENAI_BASE_URL are required; OPENAI_API_KEY is optional.
This reads the process environment without loading dotenv. Explicit
completion arguments override environment values. Model IDs may contain
slashes; the optional `openai/` prefix selects the wire protocol only.

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `default_model` | `str \| None` | `None` | Model ID used when `OPENAI_MODEL` is not set. |
| `thinking` | `bool \| None` | `None` | Same as the `LiteLLMModel` option. |
| `lifecycle` | `LiteLLMLifecycle \| None` | `None` | Same as the `LiteLLMModel` option. |
| `prompt_cache` | `bool` | `True` | Same as the `LiteLLMModel` option. |
| `**completion_args` | `Any` | Optional | Extra arguments that override environment values. |

```python
from harnest.model import LiteLLMModel

model = LiteLLMModel.from_openai_environment()  # reads OPENAI_MODEL and OPENAI_BASE_URL
```

</Accordion>
