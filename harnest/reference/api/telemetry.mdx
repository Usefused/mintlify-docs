## Exporter factory contract

| Requirement | Behavior |
|---|---|
| Unique `TelemetryExporter.name` | Duplicate names stop runtime startup |
| Synchronous, zero-argument factory | Runs once during runtime bootstrap |
| `traces`, `logs`, or both | Metrics exporters are not supported |
| `order=` | Resolves factories in ascending lifecycle order |
| Startup failure | Already-created exporters are shut down |

## Environment controls

| Variable | Effect |

| `OTEL_SERVICE_NAME` | Sets the service identity |

| `HARNEST_LOG_CONSOLE=false` | Disables JSON logs on stderr |
| `HARNEST_OTEL_ENABLED=false` | Disables the environment-configured OTLP sink |

## configure_observability

Configure console logging and optional OTLP traces/logs once per process.

```python
configure_observability(
    service_name: str,
    *,
    framework: str,
    service_version: str | None = None,
    span_exporter: Any | None = None,
    log_exporter: Any | None = None,
    exporters: Sequence[TelemetryExporter] = (),
    exporter_factories: Sequence[Any] = (),
    use_global_providers: bool = False,
    set_global_providers: bool = True,
) -> TelemetryState
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `service_name` | `str` | Required | Service name reported with telemetry. |
| `framework` | `str` | Required | Agent framework, `"adk"` or `"langgraph"`. |
| `service_version` | `str \| None` | `None` | Service version reported with telemetry. |
| `span_exporter` | `Any \| None` | `None` | Single span exporter to use. |
| `log_exporter` | `Any \| None` | `None` | Single log exporter to use. |
| `exporters` | `Sequence[TelemetryExporter]` | `()` | Named telemetry destinations. |
| `exporter_factories` | `Sequence[Any]` | `()` | Functions that build exporters at startup. |
| `use_global_providers` | `bool` | `False` | Add Harnest's processors to existing global OpenTelemetry providers when they support it. |
| `set_global_providers` | `bool` | `True` | Reuse capable global providers, or register Harnest's new providers as the global ones. |

