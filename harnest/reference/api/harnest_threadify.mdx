## BusinessFilter

Select authored steps and scalar attributes; discard all events and links.

```python
BusinessFilter(
    spans: tuple[str, ...] = ('harnest.request', 'harnest.decision.evaluate', 'business.*'),
    attributes: tuple[str, ...] = (),
    max_string_length: int = 256,
) -> None
```

## Threadify

Opt-in SDK/OTLP integration, configured without import-time credentials or I/O.

```python
Threadify(
    *,
    service_name: str,
    api_key_env: str = 'THREADIFY_API_KEY',
    filter: BusinessFilter | None = None,
    business_tools: tuple[str, ...] = (),
    otlp_endpoint: str | None = None,
    otlp_headers: Mapping[str, str] | None = None,
    connection_options: Mapping[str, Any] | None = None,
    timeout: float = 10.0,
    max_sessions: int = 10000,
) -> None
```

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `service_name` | `str` | Required | Service name reported to Threadify, such as `"support-agent"`. |
| `api_key_env` | `str` | `'THREADIFY_API_KEY'` | Environment variable that holds the Threadify API key. |
| `filter` | `BusinessFilter \| None` | `None` | Which spans and attributes are exported. Defaults to `BusinessFilter()`. |
| `business_tools` | `tuple[str, ...]` | `()` | Tool names whose outcomes are recorded. Other tools are not exported. |
| `otlp_endpoint` | `str \| None` | `None` | Standard OTLP/HTTP traces endpoint. When set, spans go there instead of the native SDK transport. |
| `otlp_headers` | `Mapping[str, str] \| None` | `None` | Headers sent to the OTLP endpoint. |
| `connection_options` | `Mapping[str, Any] \| None` | `None` | Extra options for the Threadify SDK connection. |
| `timeout` | `float` | `10.0` | Time limit in seconds for connecting and flushing. |
| `max_sessions` | `int` | `10000` | Maximum number of session links kept in memory. |

```python
from harnest_threadify import Threadify

threadify = Threadify(service_name=...)
```
