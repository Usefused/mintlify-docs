## Threadify

Opt-in SDK/OTLP integration, configured without import-time credentials or I/O.

```python
Threadify(
    *,
    service_name: str,
    api_key_env: str = 'THREADIFY_API_KEY',
    filter: BusinessFilter | None = None,
    business_tools: tuple[str, ...] = (),
    otlp_endpoint: str | None = None,
    otlp_headers: Mapping[str, str] | None = None,
    connection_options: Mapping[str, Any] | None = None,
    timeout: float = 10.0,
    max_sessions: int = 10000,
) -> None
```
