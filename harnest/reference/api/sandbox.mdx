## Sandbox

Declare one lazy sandbox usable by managed ADK and LangGraph agents.

The backend returned by `factory` implements `SandboxBackend.execute`
and enforces isolation. ADK executor providers require the ADK framework.
Compilation never connects to provider infrastructure.

Obtain this object from the owning Harnest API; its constructor includes runtime bindings.

Fields (`—` means no declared default):

| `timeout_seconds` | `int \| None` | `None` |
| `metadata` | `Mapping[str, Any]` | `dict()` |
| `network_policy` | `SandboxNetworkPolicy \| None` | `None` |

### Sandbox.provider

```python
Sandbox.provider(
    factory: Callable[[], Any],
    *,
    name: str = 'custom',
    timeout_seconds: int | None = None,
    metadata: Mapping[str, Any] | None = None,
    network_policy: SandboxNetworkPolicy | None = None,
    adapter_options: Mapping[str, Any] | None = None,
) -> 'Sandbox'
```

Configure a portable provider; native ADK factories remain compatible.

Provider-specific SDK settings belong in the factory. `adapter_options`
configures only the native framework adapter, while JSON metadata and an
optional network policy are forwarded to each request. A policy requires
provider capability declarations.

<Accordion title="Parameters and example">

| Parameter | Type | Default | Description |
|---|---|---|---|
| `factory` | `Callable[[], Any]` | Required | Function that creates your backend. It runs on first use, so put connection settings and credentials there. |
| `name` | `str` | `'custom'` | Backend name recorded for this provider, such as `"company-sandbox"`. |
| `timeout_seconds` | `int \| None` | `None` | Time limit for each execution, in seconds. |
| `metadata` | `Mapping[str, Any] \| None` | `None` | Metadata passed to the provider with each request. |
| `network_policy` | `SandboxNetworkPolicy \| None` | `None` | Network egress the provider must enforce. Harnest fails before the first run if the provider cannot. |
| `adapter_options` | `Mapping[str, Any] \| None` | `None` | Options for the framework adapter. |

```python
from harnest.sandbox import Sandbox

sandbox = Sandbox.provider(factory=...)
```

## cleanup_control

Admit resource release under a fresh finite deadline, never execution.

Provider I/O must use remaining() as its transport timeout and check() before
each side effect. This cooperative scope cannot interrupt arbitrary Python.
Nested cleanup inherits the original cleanup deadline and cannot renew it.

