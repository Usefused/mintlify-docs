

## Framework storage integration

`HarnestStore.framework_checkpointer()` uses Harnest's selected framework and returns the adapter used by advanced graphs. Declare the same store through lifecycle storage. Framework-owned wrappers live in [`harnest.frameworks.adk`](/harnest/reference/api/frameworks-adk) and [`harnest.frameworks.langgraph`](/harnest/reference/api/frameworks-langgraph). See [Checkpoints](/harnest/runtime/checkpoints).
