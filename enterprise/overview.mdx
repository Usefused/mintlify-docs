## What Enterprise includes

| Capability | Details |
|---|---|
| **Local Registry** | Self-hosted `ghcr.io/usefused/fused-registry` container for private API contracts, discovery artifacts, and offline SDK compilation, with permission-gated fallback to Fused Cloud for public APIs. |
| **Company SSO & governance** | Organization identity integration, team-scoped roles, and fine-grained permissions including `catalogue.cloud.read` and `catalogue.cloud.publish`. |
| **Unrestricted self-hosted capacity** | No artificial ceilings on buckets, services, SDKs, MCP servers, Unified Apps, concurrency, or execution history when you self-host the Engine. |
| **Shared infrastructure footprint** | Local Registry requires no NATS broker and can share the same PostgreSQL database as your Fused Engine with zero table collisions. |
