`fused-cli` is the official command-line interface for Fused. You describe a business capability in plain English, and the CLI uses Fused's intent AI to map that description to the right services, endpoints, and authentication patterns — then generates a fully typed SDK or MCP server ready for your codebase.

## How it works

When you run `fused-cli create`, Fused's intent AI parses your natural language description and identifies the third-party services and API endpoints needed to fulfil the capability you described. The result is then presented in an **interactive Cart UI** where you can review every endpoint that was selected, add endpoints you want to include, and remove any you don't need — before a single line of code is generated.

Once you confirm the cart, `fused-cli` calls the Fused build service and either:

- Downloads a **`.zip` archive** containing your SDK or MCP server, ready to drop into your project, or
- **Deploys the server directly to Fused-Run** (TypeScript MCP servers only) and returns a live SSE URL you can point Claude, Cursor, or any MCP-compatible agent at immediately.

## The three commands

| Command | What it does |
|---------|-------------|
| [`create`](/cli/create) | Generates a brand-new SDK or MCP server from a natural language description |
| [`update`](/cli/update) | Rebuilds an existing SDK using its previous configuration as the baseline |
| [`download`](/cli/download) | Fetches the `.zip` archive of an already-built SDK or MCP server |

## Supported targets

`fused-cli` can generate two types of output, each in two languages:

**SDK** — A typed client library you import directly into your own application code.  
Supported languages: `typescript` (default), `python`

**MCP Server** — A Model Context Protocol server that exposes your integrations as tools an AI agent can call.  
Supported languages: `typescript` (default), `python`

## Fused-Run deployment

When you generate a TypeScript MCP server, you can add the `--deploy` flag to publish it instantly to **Fused-Run**, Fused's managed MCP hosting service. After the build completes you receive a persistent SSE endpoint URL — no infrastructure to manage, no Docker image to build.

<Note>
  `--deploy` is only supported for MCP servers written in TypeScript. Python MCP servers and all SDK targets are downloaded as a `.zip` archive.
</Note>
