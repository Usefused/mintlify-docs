`fused-cli` is a single self-contained binary with no runtime dependencies. Choose the installation method that fits your workflow, then set your API key and you are ready to start generating SDKs and MCP servers.

## Install

<Tabs>
  <Tab title="macOS / Linux">
    **One-line install script (recommended)**

    Run the following command in your terminal. It downloads the latest release and places the binary at `/usr/local/bin/fused-cli`.

    ```bash
    curl -sSL https://raw.githubusercontent.com/Usefused/cli/main/install.sh | bash
    ```

    To install a specific version, set the `VERSION` environment variable before piping:

    ```bash
    curl -sSL https://raw.githubusercontent.com/Usefused/cli/main/install.sh | VERSION=v1.0.0 bash
    ```

    <Note>
      The script may prompt for your password if it needs `sudo` access to write to `/usr/local/bin`. You can also install to a directory inside your `$PATH` that you already own.
    </Note>
  </Tab>
  <Tab title="Windows (PowerShell)">
    **One-line install script (recommended)**

    Open PowerShell and run:

    ```powershell
    irm https://raw.githubusercontent.com/Usefused/cli/main/install.ps1 | iex
    ```

    The binary is installed to `%LOCALAPPDATA%\Programs\fused-cli` and added to your `PATH`.

    To install a specific version, set `$env:VERSION` first:

    ```powershell
    $env:VERSION="v1.0.0"; irm https://raw.githubusercontent.com/Usefused/cli/main/install.ps1 | iex
    ```
  </Tab>
  <Tab title="Go Install">
    If you have Go 1.21 or later installed, you can install `fused-cli` directly from the module proxy:

    ```bash
    go install github.com/Usefused/cli@latest
    ```

    The binary is placed in your `$GOPATH/bin` directory. Make sure that directory is on your `PATH`.

    To install a specific version, replace `latest` with the desired tag:

    ```bash
    go install github.com/Usefused/cli@v1.0.0
    ```
  </Tab>
</Tabs>

### Manual download

If you prefer to manage binaries yourself, download the archive for your platform from the [GitHub Releases page](https://github.com/Usefused/cli/releases), extract it, and place the `fused-cli` binary in the appropriate location:

- **macOS / Linux:** `/usr/local/bin/fused-cli`
- **Windows:** `%LOCALAPPDATA%\Programs\fused-cli\fused-cli.exe`

## Verify the installation

After installing, confirm `fused-cli` is available on your `PATH`:

```bash
fused-cli --help
```

You should see the top-level help output listing the available commands. If you see a "command not found" error, check that the install directory is included in your `PATH`.

## Configure your API key

Every `fused-cli` command authenticates with the Fused API using your personal API key. Set it as an environment variable so you never have to type it again:

```bash
export FUSED_API_KEY="sk_test_..."
```

Add this line to your shell profile (e.g. `~/.zshrc`, `~/.bashrc`, or `~/.bash_profile`) to persist it across sessions.

If you prefer not to use an environment variable, you can pass the key directly to any command with the `--api-key` flag:

```bash
fused-cli create --api-key "sk_test_..." --name my-sdk -d "..."
```

<Tip>
  Find your API key in the Fused Dashboard under **Settings → API Keys**. Create a new key if you haven't already — treat it like a password and never commit it to version control.
</Tip>

## Upgrade to a newer version

Re-run the same install command you used originally. The install script and `go install` both pull the latest release and overwrite the existing binary.

To pin a specific version, use the `VERSION` variable or tag as shown in the install steps above.
