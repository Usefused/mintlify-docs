`fused-cli download` fetches the `.zip` archive of an SDK or MCP server that has already been built in Fused. Use it to retrieve an artifact you generated through the Fused Dashboard, to grab a specific historical version, or to get a local copy of something a teammate generated in an earlier CLI session.

## Usage

```bash
fused-cli download <name>[@version] [flags]
```

## Version syntax

By default, `fused-cli download` retrieves the latest built version. To download a specific version, append `@<version>` to the name:

```bash
fused-cli download sales-mcp              # latest version
fused-cli download sales-mcp@1.2.0       # version 1.2.0
```

## Flags

<ParamField path="--output, -o" type="string">
  The local directory where the `.zip` archive is saved and extracted. Defaults to the current working directory. The directory is created if it does not already exist.
</ParamField>

<ParamField path="--api-key" type="string">
  Your Fused API key. Overrides the `FUSED_API_KEY` environment variable for this invocation.
</ParamField>

## Examples

<CodeGroup>
  ```bash Download the latest version
  fused-cli download sales-mcp
  ```

  ```bash Download a specific version
  fused-cli download sales-mcp@1.2.0
  ```

  ```bash Download to a specific directory
  fused-cli download sales-mcp@1.2.0 --output ./my-agent
  ```
</CodeGroup>

## When to use `download`

- **Dashboard-generated artifacts.** When you build an SDK or MCP server from the Fused web dashboard and want to pull the result to your local machine.
- **Sharing across machines.** If a teammate generated an artifact and you need a local copy without running the full `create` flow yourself.
- **Pinning a version.** When you need to lock your project to a specific artifact version that you know works, regardless of subsequent updates.
- **Re-downloading after a lost file.** If you accidentally deleted the local `.zip` from a previous `create` or `update` run, `download` lets you retrieve it again without rebuilding.

<Info>
  `download` only works for artifacts that were built and stored in Fused — it cannot fetch a Fused-Run deployment as a `.zip`. If you need the source code for a deployed MCP server, use `fused-cli download` with the server's name and the version that was deployed.
</Info>
