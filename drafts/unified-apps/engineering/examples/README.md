# Billing support brief sample

This source accompanies the engineering article in `../post.md`.

## Local contract tests

With Node 24, run from this directory:

```bash
npm install --ignore-scripts --no-audit --no-fund
npm test
node --import ./fused-test-loader.mjs capture-example.mjs
```

The loader replaces only Fused's hosting registration and provider bindings. Tests call the real `buildBrief` implementation and Zod schemas with synthetic responses. They do not contact Stripe. `partial-result.json` is generated by the final command.

## Fused plan

The source uses the `stripe` service reference and version `2026-07-29.dahlia` enabled in the demonstration workspace. Use the same enabled reference in both source and YAML in your own workspace.

```bash
fused-cli app plan -f billing-brief.yaml --no-input --json
```

The plan compiled successfully. Deployment and live provider execution are separate steps and were not performed for this article. Store a suitable Stripe credential in the selected Fused bucket before deployment. The caller must authorize the operator and resolve their customer ID before invoking the action.
