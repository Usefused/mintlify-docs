Choose where your Fused Engine runs. Both options give you a workspace for services, credentials, SDKs, MCP servers, and Unified Apps.

<CardGroup cols={2}>
  <Card title="Use Fused Cloud" icon="cloud" href="/setup/fused-cloud">
    Create an account and let Fused provision your Engine and managed database. No PostgreSQL setup or runtime installation required.
  </Card>
  <Card title="Self-host Fused" icon="server" href="/setup/self-hosted">
    Run the Engine in your own infrastructure. You supply PostgreSQL, a license key, and a persistent encryption key.
  </Card>
</CardGroup>

| | Fused Cloud | Self-hosted Fused |
|---|---|---|
| Engine deployment | Provisioned by Fused | Deployed by you |
| PostgreSQL | Managed by Fused | Supplied by you |
| Runtime configuration and encryption key | Managed by Fused | Configured and retained by you |
| Workspace address | Provided after provisioning | Your Engine's HTTP address |
| First step | Choose **Deploy in Fused Cloud** at signup | Choose **License key only** at signup |

<Note>
  Fused Cloud includes a managed database. The PostgreSQL, Docker, `engine.yaml`, and encryption key instructions in the self-hosting guide apply only when you run the Engine yourself.
</Note>

Already have a workspace? Open its dashboard, or [install and connect the CLI](/quickstart#install) to start building an App.
